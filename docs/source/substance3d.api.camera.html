frame_turntable(camera, objects=None, frame_fit=1.5, timecode='Usd.TimeCode.Default().GetValue()', aspect_ratio=None)

Frame a camera using the bounding cylinder turntable framing algorithm.

Unlike frame(), this method computes the minimum bounding cylinder of the objects around the Y-axis and frames the camera to fit the cylinder. This produces consistent framing for turntable renders: the object always occupies the same screen area regardless of rotation around the Y-axis.

Parameters:

  • camera (PrimHandler) – the existing camera to frame with

  • objects (list[PrimHandler] | PrimHandler | StageHandler | None) – the object(s) the camera should frame

  • frame_fit (float) – 1.0 is a tight fit, increase to add space around the frame

  • timecode (float) – the timecode used to evaluate the geometry

  • aspect_ratio (float | None) – the aspect ratio the camera will be rendered at. When provided, the camera aperture is updated to match so the subject is tightly framed in the final render. When omitted, the camera’s current aperture aspect ratio is used (unchanged behavior).

Returns:

the updated and now framed camera

Return type:

PrimHandler
