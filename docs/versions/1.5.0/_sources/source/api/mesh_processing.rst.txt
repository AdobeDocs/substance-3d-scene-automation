.. class:: UnwrapOp

   Seam, parameterize and pack all meshes in the given subtree into a single UV tile.

    .. rubric:: Attributes

    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **mode**                                         | enum     | UnwrapMode.Default | Mode of the unwrap driver (see note below).                   |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **input_normal_attribute_name**                  | str      | ""                 | Optional input normals attribute name to segment hard edges.  |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **enable_sharing_uvs_between_instances**         | bool     | False              | Share generated UVs between instances of the scene?           |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **output_attribute_name**                        | str      | "primvars:st"      | Output UV attribute name.                                     |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **packing.padding_size**                         | float    | 0.001              | Padding size around each island.                              |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **packing.max_num_uv_tiles**                     | int      | 1                  | Maximum number of UV tiles to generate.                       |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **packing.num_island_rotations**                 | int      | 4                  | Number of possible rotation for every island.                 |
    +----------------------------------------+---------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.enable_partition_chart**          | bool     | True               | Enable chart splitting algorithm.                             |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.enable_elongated_islands**        | bool     | True               | Enable elongated island detection.                            |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.elongation_threshold**            | float    | 20.0               | Threshold to consider a chart elongated.                      |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.chunks_elongation**               | float    | 10.0               | Max elongation for segmented chunks of elongated islands.     |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.max_cluster_confidence**          | float    | 0.97               | Threshold for the dot product between face and plane normals. |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.max_num_iterations**              | int      | 7                  | Maximum number of iterations for the post process.            |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.max_num_outliers**                | int      | 1                  | Maximum number of clustering outliers in the face one ring .  |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+
    | **segmentation.input_uv_attribute_name**         | str      | ""                 | Use input UVs for seams instead of computing them.            |
    +--------------------------------------------------+----------+--------------------+---------------------------------------------------------------+

    .. note::

       Possible values for the ``mode`` attribute:

       - ``UnwrapMode.Default``: The default workflow. Offers overlap-free UV layouts of high quality, especially suited for organic meshes.
       - ``UnwrapMode.Fast``: Fast organic workflow. Allows to get the UV layout of desired distortion quality relatively fast, at expense of more cuts and possible self-overlaps.
       - ``UnwrapMode.HardEdge``: Fast workflow for non-organic meshes. The workflow is based on improved triplanar algorithm that yields good results for axis-aligned models.

.. class:: SubdivisionOp

   Subdivide all meshes in the given subtree.

    .. rubric:: Attributes

    +------------------------+---------+-------------------------------+---------------------------------------------+
    | **num_levels**         | int     | 1                             | Number of subdivision levels requested.     |
    +------------------------+---------+-------------------------------+---------------------------------------------+
    | **use_limit_surface**  | bool    | False                         | Interpolate all data to the limit surface.  |
    +------------------------+---------+-------------------------------+---------------------------------------------+
    | **scheme**             | str     | SubdivisionScheme.Automatic   | Subdivision scheme to use.                  |
    +------------------------+---------+-------------------------------+---------------------------------------------+

    .. note::

       Possible values for the ``scheme`` attribute:

       - ``SubdivisionScheme.Bilinear``: Useful to subdivide a mesh prior to applying a displacement map.
       - ``SubdivisionScheme.CatmullClark``: More widely used and suited to quad-dominant meshes.
       - ``SubdivisionScheme.Loop``: For (and requires) purely triangulated meshes.
       - ``SubdivisionScheme.Automatic``: Chooses between Catmull-Clark for quad-dominant meshes.

.. class:: RemoveDegenerateFacesOp

   Remove degenerate faces from each mesh in the scene, in-place.
   The current method assumes input mesh is triangular.
   Non-degenerate facets adjacent to degenerate facets may be
   re-triangulated as a result of the removal.

.. class:: ComputeVertexNormalsOp

  Create or update the mesh attribute containing vertex normals.

   .. rubric:: Attributes

   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+
   | **output_attribute_name**                 | str                 | "primvars:normals"                   | Name of the mesh attribute containing face normals.                 |
   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+
   | **weight_type**                           | NormalWeightingType | NormalWeightingType.Angle            | Per-vertex normal averaging weighting type.                         |
   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+
   | **weighted_corner_normal_attribute_name** | str                 | "primvars:weightedCornerNormals"     | Precomputed weighted corner attribute name.                         |
   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+
   | **recompute_weighted_corner_normals**     | bool                | False                                | Whether to recompute the weighted corner normal attribute.          |
   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+
   | **keep_weighted_corner_normals**          | bool                | False                                | Whether to keep any newly added weighted corner normal attribute.   |
   +-------------------------------------------+---------------------+--------------------------------------+---------------------------------------------------------------------+

    .. note::

       Possible values for the ``weight_type`` attribute:

       - ``NormalWeightingType.Angle``: Incident face normals are averaged weighted by incident angle of vertex.
       - ``NormalWeightingType.Uniform``: Incident face normals have uniform influence on vertex normal.
       - ``NormalWeightingType.Area``: Incident face normals are averaged weighted by area of the corner triangle.

.. class:: ComputeTangentsAndBitangentsOp

  Compute mesh tangents and bitangents in local coordinate system.
  Create or update related mesh attributes, the new/updated tangent (first) and bitangent (second) attributes.

   .. rubric:: Attributes

   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **tangent_attribute_name**      | str                 | "primvars:tangents"           | Name of the mesh attribute containing tangents.                                                               |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **bitangent_attribute_name**    | str                 | "primvars:bitangents"         | Name of the mesh attribute containing bitangents.                                                             |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **output_element_type**         | MeshAttributeElement| MeshAttributeElement.Indexed  | Output element type. Can be either `MeshAttributeElement.Corner` or `MeshAttributeElement.Indexed`.           |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **pad_with_sign**               | bool                | False                         | Whether to pad the tangent/bitangent vectors with a 4th coordinate indicating the sign of the UV triangle     |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **orthogonalize_bitangent**     | bool                | False                         | Whether to compute the bitangent as sign * cross(normal, tangent)                                             |
   |                                 |                     |                               | If false, the bitangent is computed as the derivative of v-coordinate                                         |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
   | **keep_existing_tangent**       | bool                | False                         | Whether to recompute tangent if the tangent attribute (specified by tangent_attribute_name) already exists    |
   |                                 |                     |                               |                                                                                                               |
   |                                 |                     |                               | - If true, bitangent will be computed by `sign * normalized(cross(normal, existing_tangent))`,                |
   |                                 |                     |                               |   `orthogonalize_bitangent` must be true                                                                      |
   |                                 |                     |                               |                                                                                                               |
   |                                 |                     |                               | - If false, the tangent will be recomputed and potentially overwritten.                                       |
   +---------------------------------+---------------------+-------------------------------+---------------------------------------------------------------------------------------------------------------+
