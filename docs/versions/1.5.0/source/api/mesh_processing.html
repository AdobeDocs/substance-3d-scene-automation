substance3d.api.mesh_processing

process(parent, operators)

Process a list of mesh operators on the given target and its subtree.

Parameters:

  • parent (substance3d.api.core.prim_handler.PrimHandler | substance3d.api.core.stage_handler.StageHandler) – Given targen can be a scene or an object

  • operators (list[substance3d.api.mesh_processing.operators.MeshOperator]) – A list of mesh operators

Seam, parameterize and pack all meshes in the given subtree into a single UV tile.

Attributes

enum

int

1

Maximum number of clustering outliers in the face one ring .

segmentation.input_uv_attribute_name

str

“”

Use input UVs for seams instead of computing them.

Note

Possible values for the mode attribute:

  • UnwrapMode.Default: The default workflow. Offers overlap-free UV layouts of high quality, especially suited for organic meshes.

  • UnwrapMode.Fast: Fast organic workflow. Allows to get the UV layout of desired distortion quality relatively fast, at expense of more cuts and possible self-overlaps.

  • UnwrapMode.HardEdge: Fast workflow for non-organic meshes. The workflow is based on improved triplanar algorithm that yields good results for axis-aligned models.

class SubdivisionOp

Subdivide all meshes in the given subtree.

Attributes

num_levels

int

1

Number of subdivision levels requested.

use_limit_surface

bool

False

Interpolate all data to the limit surface.

scheme

str

SubdivisionScheme.Automatic

Subdivision scheme to use.

Note

Possible values for the scheme attribute:

  • SubdivisionScheme.Bilinear: Useful to subdivide a mesh prior to applying a displacement map.

  • SubdivisionScheme.CatmullClark: More widely used and suited to quad-dominant meshes.

  • SubdivisionScheme.Loop: For (and requires) purely triangulated meshes.

  • SubdivisionScheme.Automatic: Chooses between Catmull-Clark for quad-dominant meshes.

  • NormalWeightingType.Uniform: Incident face normals have uniform influence on vertex normal.

  • NormalWeightingType.Area: Incident face normals are averaged weighted by area of the corner triangle.

class ComputeTangentsAndBitangentsOp

Compute mesh tangents and bitangents in local coordinate system. Create or update related mesh attributes, the new/updated tangent (first) and bitangent (second) attributes.

Attributes

tangent_attribute_name

str

“primvars:tangents”

Name of the mesh attribute containing tangents.

bitangent_attribute_name

str

“primvars:bitangents”

Name of the mesh attribute containing bitangents.

output_element_type

MeshAttributeElement

MeshAttributeElement.Indexed

Output element type. Can be either MeshAttributeElement.Corner or MeshAttributeElement.Indexed.

pad_with_sign

bool

False

Whether to pad the tangent/bitangent vectors with a 4th coordinate indicating the sign of the UV triangle

orthogonalize_bitangent

bool

False

Whether to compute the bitangent as sign * cross(normal, tangent) If false, the bitangent is computed as the derivative of v-coordinate

keep_existing_tangent

bool

False

Whether to recompute tangent if the tangent attribute (specified by tangent_attribute_name) already exists

  • If true, bitangent will be computed by sign * normalized(cross(normal, existing_tangent)), orthogonalize_bitangent must be true

  • If false, the tangent will be recomputed and potentially overwritten.
