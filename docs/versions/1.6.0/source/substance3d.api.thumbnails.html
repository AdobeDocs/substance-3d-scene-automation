substance3d.api.thumbnails.thumbnails module

get(parent)

Retrieve the thumbnail image filepath. If a StageHandler is provided, its defaultPrim will be used as the target prim.

Parameters:

parent (PrimHandler | StageHandler) – The target primhandler or stagehandler.

Returns:

The thumbnail value if found, otherwise None.

Raises:

ValueError – If the StageHandler has no defaultPrim.

get_from_filepath(filename)

Retrieve the thumbnail image filepath in a valid scene file.

Parameters:

filename (str | Path) – Path to the valid scene file to read the thumbnail from.

Returns:

The thumbnail value if found, otherwise None.

remove(parent)

Remove the thumbnail reference from the target object if present. If a StageHandler is provided, its defaultPrim will be used as the target.

Parameters:

parent (PrimHandler | StageHandler) – The target primhandler or stagehandler.

render(parent, output_filename, resolution=(512, 512), reference_result=True, custom_template=None)

Render a thumbnail image of the given stage and optionally reference it on the default prim.

Parameters:

  • parent (StageHandler) – The stage to render.

  • output_filename (str | Path) – Output image file path.

  • resolution (tuple[int, int]) – Thumbnail resolution as (width, height) in pixels. Defaults to (512, 512).

  • reference_result – When True, references the rendered image on the stage’s default prim.

  • custom_template (str | Path | None) –

    Optional path to a USD template file containing lights, cyclorama, and a camera. The parent stage is referenced into the first xform prim matching *asset*. When a template is provided, the following adjustments are applied automatically:

    • The asset is rotated to match the template’s up-axis.

    • The asset is moved to ground level.

    • The first camera found in the template is framed on the asset.

set(parent, filepath)

Set a thumbnail image by referencing an external filepath. If a StageHandler is provided, its defaultPrim will be used as the target prim.

Parameters:

  • parent (PrimHandler | StageHandler) – The target primhandler or stagehandler.

  • filepath (str | Path) – Path to the thumbnail image file to associate.

Raises:

ValueError – If the StageHandler has no defaultPrim, or if the thumbnail command fails.
