convert_vertex_colors_to_materials(objects, material_name_pattern, subset_name_pattern, parent)

Using the displayColor primvar on the provided meshes, locates faces that have a solid color, creates a single material for each of those colors, and then binds the material to the mesh or to a newly created geomsubset of the mesh.

When a color covers all faces of a mesh the material for that color is bound directly to the mesh. When a color covers only a subset of faces on a mesh, a geom subset is created on the mesh and the material is bound to that. If a mesh has some non-solid colored faces, the mesh will be skipped.

Callers may specify either the meshes to operate on, or they may specify a single parent prim that contains the meshes.

Parameters:

  • objects (PrimHandler | list[PrimHandler]) – A prim handler or a list of prim handlers to meshes, or a single parent prim

  • material_name_pattern (str) – The pattern used to name any created materials, it may contain ‘{r}’, ‘{g}’ and ‘{b}’ which will be replaced by the corresponding color channel value of the vertex color (e.g. ‘mat_{r}_{g}_{b}’)

  • subset_name_pattern (str) – The pattern used to name any created geom subsets, it may contain ‘{r}’, ‘{g}’ and ‘{b}’ which will be replaced by the corresponding color channel value of the vertex color (e.g. ‘subset_{r}_{g}_{b}’)

  • parent (PrimHandler) – The parent under which the materials will be created
